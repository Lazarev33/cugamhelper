# Помощник 2 смены — Telegram-бот с CLI-меню для VPS (v2.1)

**Имя бота в Telegram: «Помощник 2 смены».** При запуске он устанавливает это отображаемое имя через Telegram Bot API (основное и русскоязычное). Имя пользователя `@...` остаётся прежним: его можно задать или поменять только через @BotFather. При временной ошибке Telegram бот продолжает работу, а проблема отображается в журнале.

Бот удаляет даты и тире из списков вида `26008178-03.11.2026` и возвращает исходные идентификаторы. **Без изменения порядка, дубликатов и ведущих нулей**. Неверные строки блокируют весь результат, чтобы не потерять номер незаметно.

**Новое в v2:** управление ботом через интерактивное меню **непосредственно в SSH-терминале VPS**, без браузера и открытых портов для панели. Бот запускается как `systemd`-служба и продолжает работать после закрытия SSH.

## Установка на VPS

Поддерживается **Ubuntu/Debian с systemd**, Python **3.10+**, доступ `sudo`. База данных не нужна. Нужен доступ VPS в интернет к Telegram.

1. Создай бота через [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. Распакуй ZIP на VPS и перейди в папку `tg-number-cleaner-v2`.
3. Выполни:

   ```bash
   sudo bash install.sh
   sudo numberbot
   ```

4. В меню выбери **1**, вставь токен от BotFather (он не отображается), затем **2** для запуска.
5. Отправь боту сообщение со списком номеров.

**Для обновления с v2.0:** распакуй новый архив на VPS и повторно выполни `sudo bash install.sh` из новой папки. Токен повторно вводить не нужно. **Повторная установка обновляет код и зависимости, но не стирает сохранённый токен**. Если бот до обновления работал, служба перезапустится автоматически.

```text

═════════════════════════════════════════════
  Бот:   ● работает
  Токен: настроен
─────────────────────────────────────────────
  1. Установить / заменить токен
  2. Запустить бота
  3. Остановить бота
  4. Перезапустить бота
  5. Подробный статус
  6. Последние 60 строк журнала
  7. Журнал в реальном времени
  8. Проверка кода (тесты)
  0. Выход
```

В любое время набери `sudo numberbot` (из любой папки). Также доступны прямые команды:

```bash
sudo numberbot status
sudo numberbot restart
sudo numberbot logs
sudo numberbot follow
sudo numberbot test
```

При выборе пункта **0** или закрытии SSH работающий бот **не останавливается**.

## Пример обработки

Входящее сообщение:

```text
26008178-03.11.2026
26008179-03.11.2026
26009490-20.11.2026
```

Ответ:

```text
26008178
26008179
26009490
```

Поддерживается ввод уже очищенных номеров. Результат разбивается на несколько сообщений, если он слишком длинный.

## Безопасность и устройство

- Файл токена: `/etc/tg-number-cleaner/bot.env` (`root:tgnumclean`, права `0640`). Меню принимает токен без отображения ввода. Не пересылай токен никому.
- Процесс бота запущен от отдельного пользователя `tgnumclean` с минимальными правами; исходники расположены в `/opt/tg-number-cleaner`.
- Веб-панели, слушающего TCP-порта управления и публичных HTTP-эндпоинтов нет. Бот использует исходящие соединения к Telegram (long polling).
- Журнал доступен через `journalctl`; содержимое обрабатываемых списков бот в него не записывает.
- Чтобы остановить бота: `sudo numberbot stop`. Чтобы снова запустить: `sudo numberbot start`.
- Для тестов без Telegram: `python3 -m unittest discover -s . -p 'test_*.py' -v`.
- Код и зависимости обновляются **повторным запуском `install.sh` из новой распаковки**. Это не автоматический updater.

### Запуск локально без VPS (по-старому)

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
# Вставь токен в .env
.venv/bin/python bot.py
```

На VPS используй `sudo numberbot`: файл `.env` для этого не нужен. Не публикуй `.env`, `bot.env` или токены в репозиториях.
