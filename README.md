# Помощник 2 смены

Telegram-бот для сотрудников склада. Версия v2.5.1. Поддерживаются Ubuntu и Debian с systemd, Python 3.10+ и aiogram 3.x.

## Быстрый старт и переход с v2.4.0

На Ubuntu/Debian с systemd выполни один раз. Для перехода со старой установки подойдёт тот же установщик. Токен, настройки, владельца и каталог он сохраняет.

```bash
(
  set -e
  sudo apt-get update
  sudo apt-get install -y git ca-certificates
  src=$(mktemp -d)
  git clone --depth 1 https://github.com/Lazarev33/cugamhelper.git "$src"
  sudo bash "$src/install.sh"
)
sudo numberbot
```

Для установки из ZIP распакуй архив, открой каталог с `install.sh` и выполни `sudo bash install.sh`, затем `sudo numberbot`.

1. На новой установке открой мастер. Введи токен от @BotFather скрытым вводом. Мастер проверит его в Telegram.
2. Введи числовой ID владельца или пропусти этот шаг. После запуска свой ID можно посмотреть командой `/myid` в личном чате с ботом.
3. Подтверди сводку. Мастер сохранит параметры и дождётся запуска службы.
4. Открой `/admin` в Telegram. В разделе «Администраторы» владелец назначает сотрудников по ID.

Дальнейшие обновления запускаются через **9 · Обновить из GitHub** или `sudo numberbot update`. Бот получает код публичного репозитория через HTTPS.

## Техническое обслуживание

В `sudo numberbot` пункт 5 открывает настройки владельца, доступа, отправки ШК и антиспама. Сброс восстанавливает параметры выдачи и защиты, сохраняя права доступа. Ограничивая доступ, включи в список нужных администраторов. CLI сохраняет доступ владельцу.

| Команда | Действие |
| --- | --- |
| `sudo numberbot setup` | Мастер настройки и запуск |
| `sudo numberbot owner` | Назначить или сменить владельца |
| `sudo numberbot settings` | Изменить настройки |
| `sudo numberbot backup` | Согласованная копия каталога, ролей и журнала в /var/backups/tg-number-cleaner |
| `sudo numberbot diagnose` | Проверить конфигурацию, SQLite, службу, зависимости, GitHub и Telegram |
| `sudo numberbot status` | Подробный статус службы |
| `sudo numberbot logs` | Последние события службы |
| `sudo numberbot follow` | Следить за журналом |
| `sudo numberbot test` | Запустить локальные проверки |

При ошибке токена снова введи его через меню. При ошибке запуска посмотри журнал. Если GitHub недоступен, проверь сеть, системное время и сертификаты VPS.

## Работа в Telegram

Открой бота и отправь `/start`. В главном меню четыре раздела.

- **ШК**. Выбери код и открой фото из чата на весь экран для сканирования. Название видно в подписи. Под изображением есть возврат на текущую страницу каталога. Список над изображением также остаётся доступным.
- **Сканировать ШК**. Нажми кнопку или введи `/scan`, отправь изображение и посмотри распознанный формат и значение. Если найдено несколько кодов, выбери нужный.
- **Очистка номеров**. Отправь список строк вида `26008178-03.11.2026`. Уже очищенные номера тоже принимаются. При обработке сохраняются порядок, ведущие нули и дубликаты.
- **Помощь**. Краткие инструкции. Команда `/help` открывает тот же экран, `/menu` возвращает в главное меню.

После очистки бот сначала отправляет отдельный отчёт, например:

```text
Обработано: 3
Ошибок: 0
Потерь: 0
```

Следующее сообщение содержит только номера, по одному на строку. Зажми его и выбери стандартное действие Telegram **Копировать**. Если список превышает лимит сообщения, бот укажет количество частей в отчёте и отправит все части по порядку. Если хотя бы одна строка некорректна, бот укажет её номер и попросит отправить весь исправленный список.

Имя в профиле бота задаётся при запуске. Управление `@username` остаётся в [@BotFather](https://t.me/BotFather).

## Как проходит обновление и откат

CLI выводит установленную версию и проверяет ревизию `main`. На актуальной ревизии завершает проверку без перезапуска. При наличии изменений запрашивает подтверждение и скачивает проверенную ревизию. Код, зависимости и тесты готовятся в новом каталоге отдельным виртуальным окружением. Действующая версия обслуживает Telegram до переключения.

При переключении systemd ждёт, пока Telegram подтвердит первый успешный запрос `getUpdates`. Для установки без токена этот этап выполняется при первом запуске после настройки. Если запуск обновления не прошёл, CLI возвращает предыдущий код, виртуальное окружение и unit-файл, затем восстанавливает работу ранее запущенной службы. Предыдущий успешный выпуск доступен через `/opt/tg-number-cleaner-releases/previous`. При сообщении о сбое проверь `sudo numberbot logs`. Обновления запускаются вручную.

Каталог и административные назначения хранятся в SQLite вне каталога выпуска. Токен хранится отдельно в `/etc/tg-number-cleaner/bot.env` с владельцем `root:tgnumclean` и правами `0640`. Процесс Telegram работает от пользователя `tgnumclean`.

## Защита от частых запросов и настройка VPS

Бот отвечает в личных чатах. При частых нажатиях на разные кнопки ШК действует один интервал на пользователя. Первое ограниченное нажатие в этом интервале показывает короткое всплывающее предупреждение. Промежуточные нажатия подтверждаются без текста. Навигация использует отдельные ограничения, повторное открытие видимого экрана пропускается.

Очистка запускается по одной операции на пользователя. Пока она выполняется, одновременные запросы пропускаются, чтобы отчёт и результат шли подряд. После завершения при слишком раннем повторе бот может отправить короткое предупреждение. Очередь принимает ограниченное число операций очистки и выдачи ШК, затем отвечает, что бот занят.

| Ключ в `settings.json` | По умолчанию | Назначение |
| --- | ---: | --- |
| `barcode_cooldown` | 2 сек. | Интервал между запросами ШК, общий для всех кодов и режимов |
| `clean_cooldown` | 5 сек. | Интервал между запросами очистки |
| `warning_interval` | 15 сек. | Интервал между текстовыми предупреждениями одному пользователю |
| `chat_interval` | 1,1 сек. | Минимальный интервал между исходящими запросами в чат |
| `global_rate` | 20/сек. | Общая скорость отправки текста, фото, документов и правок меню |
| `max_input_chars` | 16 384 | Максимальная длина входного списка в символах |
| `max_input_lines` | 1 500 | Максимальное число строк, включая пустые |
| `parallel_operations` | 8 | Активные операции ШК и очистки на весь бот |
| `queue_size` | 32 | Ожидающие операции ШК и очистки на весь бот |
| `retry_attempts` | 2 | Повторные попытки после явного ответа Telegram 429 |
| `send_timeout` | 15 сек. | Бюджет одного запроса отправки вместе с ожиданием и повторами |
| `barcode_mode` | `photo` | `photo` показывает изображение в чате, `document` отдаёт исходный PNG |
| `allowed_user_ids` | `null` | Без списка доступны все личные чаты. Массив числовых Telegram ID ограничивает доступ, пустой массив закрывает доступ всем |

Лимиты — настройки бота. Telegram может применять дополнительные ограничения. При 429 отправки ждут фактический `retry_after`. Повторяется отклонённый запрос в пределах бюджета. Сетевой сбой с неизвестным результатом доставки автоматически не повторяется. Подтверждения inline-кнопок отправляются отдельно. При насыщении их канала или собственном 429 часть подтверждений может пропускаться. Состояние хранится в памяти VPS. Повторные update подавляются до двух минут в пределах последних 8 192 событий, пользовательские записи очищаются по истечении трёх минут без действий и ограничены 4 096 записями. [Telegram Bots FAQ](https://core.telegram.org/bots/faq) · [Telegram Bot API](https://core.telegram.org/bots/api)

Технический способ настройки — файл `/etc/tg-number-cleaner/settings.json`. Повседневные изменения доступны через `sudo numberbot settings`.

## Админ-панель Telegram

Открой `/admin` в личном чате с ботом.

- **Каталог ШК** показывает активные и отключённые записи. В карточке можно открыть предпросмотр, изменить название или значение, включить, выключить или удалить запись. Удаление запрашивает подтверждение. При замене значения предпросмотр показывает старое и новое.
- **Добавить вручную** запрашивает название кнопки и значение Code 128. Проверь изображение и нажми **Сохранить**.
- **Добавить по фото** считывает изображение локально. Если найдено несколько кодов, выбери нужный, затем задай название и подтверди предпросмотр. Фото само по себе каталог не меняет.
- **Администраторы** показывает назначения. Владелец может назначить или отозвать права по числовому Telegram ID.
- **Журнал изменений** показывает последние изменения каталога и прав с временем UTC и ID автора.

`/cancel` отменяет текущий шаг, `/menu` возвращает в главное меню. Незавершённые диалоги хранятся до 10 минут. Изменения становятся доступны при следующем открытии каталога. При отзыве прав текущий диалог администратора закрывается.

### Генерация, сканирование и дубликаты

Название кнопки и значение сохраняются отдельно. Генератор создаёт Code 128 из 1–48 печатных ASCII-символов. Значение сохраняется посимвольно, включая регистр, пробелы и ведущие нули. Изображение формируется через python-barcode и Pillow при 508 dpi. Узкий модуль занимает 8 пикселей, боковые белые поля — по 80 пикселей, высота полос — 480 пикселей. По умолчанию бот показывает фото в чате. Для оригинального PNG как документа выбери «Оригинальный PNG» в настройках отправки ШК.

При сканировании zxing-cpp возвращает фактический формат и содержимое. Распознаются Code 128, EAN, QR, Data Matrix и другие форматы, поддерживаемые декодером. В каталог сохраняется только обычный Code 128 с допустимым значением. Лимиты сканера — один кадр JPEG, PNG или WebP до 5 МиБ и 8 мегапикселей, до 16 распознанных кодов и до 6 секунд на локальный процесс. Действуют общий лимитер и очередь, одновременно принимаются до двух фото на распознавание.

SQLite обеспечивает уникальность пары «формат + значение» для активных и отключённых записей. При совпадении бот показывает «Данный штрихкод уже существует!», название, значение и статус, предлагает открыть запись и восстановить её, если она выключена.

Подход к локальному декодированию изучен по [Straiko/shk](https://github.com/Straiko/shk). Обработчики и сканер проекта реализованы самостоятельно на aiogram и zxing-cpp.

### SQLite и первый запуск

Systemd создаёт каталог `/var/lib/tg-number-cleaner/` с правами `0700` для пользователя службы `tgnumclean`. В нём располагается `catalog.sqlite3`. Код релиза хранится отдельно. На первом запуске бот импортирует локальный `/etc/tg-number-cleaner/barcodes.json`, если он есть, и добавляет отсутствующие записи из встроенного каталога:

`A-POL`, `A-AKB1`, `A-OUT13`, `A-IN-S1`, `A-IN-G1`, `A-05`, `A-03`, `A-OUTP1`, `A-BR1`.

Порядок локальных записей сохраняется. Импорт выполняется в одной транзакции и повторно не запускается. После него SQLite становится источником каталога, административных назначений и журнала. Перед изменением существующей схемы создаётся согласованный резервный файл `catalog.sqlite3.schema-<версия>.bak`. Откат кода оставляет рабочую БД на месте. Для ручной резервной копии выполни `sudo numberbot backup`.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -v
```

Для локального запуска скопируй `.env.example` в `.env`, задай в нём тестовый токен и выполни `.venv/bin/python bot.py`. Один токен должен использоваться только одним запущенным клиентом polling.

`bot.py` обслуживает Telegram, `parser.py` проверяет ввод, `barcodes.py` генерирует PNG, `catalog.py` хранит каталог и права, `admin.py` обслуживает диалоги, `scanner.py` читает изображения, `protection.py` управляет нагрузкой, `settings.py` читает настройки, `cli.py` работает с systemd, `deployment.py` готовит и переключает выпуски. Файлы выполнения перечислены в `deploy-files.txt`.
