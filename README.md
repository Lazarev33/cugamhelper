# Cugam Helper — Помощник 2 смены

Telegram-бот, REST API и веб-панель для склада. Эта ветка содержит кандидат **v3.1.0** поверх инфраструктурного PR v3.0.0. Рабочая main на момент начала работ содержала v2.7.6.

- [Руководство пользователя](docs/USER_GUIDE.md) — ШК, документы и диалоги Telegram.
- [Администрирование](docs/ADMIN_GUIDE.md) — роли, диагностика и политика хранения.
- [Развёртывание](docs/DEPLOYMENT.md) — установка, systemd и HTTPS.
- [Цепочка поставки](docs/SUPPLY_CHAIN.md) — ZIP, ключи и обновления.
- [API v1](docs/API.md), [OpenAPI](docs/openapi.json), [интеграция Android](docs/ANDROID_INTEGRATION.md).
- [Модель угроз](docs/THREAT_MODEL.md), [конфиденциальность](docs/PRIVACY.md), [восстановление](docs/DISASTER_RECOVERY.md).

Для первой установки и миграции нужен доверенный ключ, полученный от владельца отдельно от ZIP. Тестовый подписанный пакет предназначен для лаборатории. Работа с документами происходит в оперативной памяти. Доставленные сообщения остаются у Telegram.
