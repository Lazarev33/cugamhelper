Лицензию проекта выбирает владелец прав после проверки вкладов и заимствований. MIT/BSD обычно допускают широкое использование при сохранении уведомлений. GPL добавляет требования при распространении, AGPL распространяет часть обязательств на сценарии сетевого использования модифицированной версии. Для закрытого проекта можно сохранить текущий статус и отдельно оформить условия доступа.
