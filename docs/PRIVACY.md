# Жизненный цикл данных

| Категория | Место и доступ | Срок |
| --- | --- | --- |
| Документы, фото, рабочие списки и результаты | RAM бота и worker, tmpfs | До завершения, отмены или TTL. В копии и метрики не входят |
| Диалоги | Память бота | Обычно 600 секунд, по настройке data_ttl |
| Экспорт | Ограниченная RAM-очередь API | До результата, ошибки или дедлайна |
| Чаты и доставка | Telegram и клиент | Определяется правилами Telegram и участниками |
| Сотрудники, роли, каталог | SQLite, доступ по ролям | Активные допуски сохраняются, отключённые очищаются по утверждённой политике |
| Посетители и журнал | SQLite | Предложение 7 и 90 суток. По умолчанию предпросмотр |
| Устройства и сессии | SQLite, проверочные хеши | Истечение сессий техническое, срок для отозванных устройств утверждается |
| Метрики | RAM процесса | До перезапуска, без идентификаторов |
| Резервные копии | Закрытый каталог VPS | Ротация после утверждения с сохранением пригодной копии |

SQLite DELETE — логическое удаление. Страницы SQLite, WAL, снапшоты и прежние копии могут содержать данные. SHA-256 копии выявляет изменение при наличии доверенной контрольной суммы. Утверждённой модели криптографического уничтожения и отдельной правовой оценки нет.
