# Безопасность и данные

Подключение Android подтверждается в личном Telegram-чате тем же аккаунтом, который указан в попытке. Одноразовый challenge истекает через пять минут. Для выдачи токенов нужны подтверждение и исходный verifier. В базе хранятся SHA-256 случайных токенов, а не значения Bearer и refresh. Веб-вход требует подтверждённой роли при каждом запросе. Bootstrap владельца выпускает новый одноразовый код из консоли VPS и отзывает его прежние веб-сессии после успешного входа. Cookie имеет HttpOnly, SameSite=Strict, в HTTPS-режиме также Secure и префикс __Host-. Изменения проверяют Origin и CSRF. Локальная сессия допустима только на loopback и в SSH-туннеле.

Проверки доступа привязаны к объекту и текущей роли. Сессии Android не обладают веб-полномочиями. Внешние запросы не выбирают Telegram-чат. Бот повторяет проверку допуска после ожидания лимитера непосредственно перед отправкой каждой части. Ранее принятые Telegram сообщения нельзя отозвать автоматически. HTTP и Telegram могут оставить неизвестный результат отдельных сетевых попыток.

Рабочие результаты живут в RAM API и бота, освобождаются при завершении или отмене. SQLite содержит устройства, ссылки привязки, проверочные хеши токенов, метаданные и административный аудит. Открытые рабочие строки не записываются на диск. В приложении отключён Uvicorn access log. В production reverse proxy не должен собирать тело запроса, cookie и авторизационные заголовки. В предлагаемом Caddyfile access log не включён, reverse proxy работает без request_buffers, предел тела 524288 байт. Не добавляйте промежуточный прокси с дисковой буферизацией. Привилегированный оператор VPS и Telegram при доставке остаются частью модели доверия.

В systemd настроены tmpfs, запрет подкачки и дампов. Для MemorySwapMax=0 требуется cgroup v2. Приложение опирается на Linux и локальный Unix-сокет. Проверяйте HTTP- и системную конфигурацию на целевом VPS. Шифрование общей SQLite остаётся HOLD.
