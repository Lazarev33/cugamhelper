# Администрирование

В sudo numberbot доступны проверка подписи манифеста, диагностика worker, предварительный просмотр хранения и инвентаризация копий. Прямые команды: sudo numberbot trust-status, worker-status, retention-preview, backups. Перед включением очистки сверьте список категорий и объём данных.

Предлагаемая политика:

```json
{"enabled":false,"visitors":7,"employees_revoked":null,"journal":90,"devices_revoked":null,"backups":null}
```

Применить согласованный JSON: sudo numberbot retention-policy ИМЯ_ФАЙЛА. Когда enabled=true, таймер запускает очистку ежедневно. Ручной sudo numberbot retention-apply подчиняется той же политике. Сроки сессий применяются независимо.

Владелец подтверждает изменение администраторов, глобальных переключателей и массовый отзыв устройств трёхминутной командой sudo numberbot approve, которую показывает соответствующий экран. Подтверждение одноразовое и связано с параметрами веб-запроса или Telegram-диалогом. В веб-панели можно завершить все свои веб-сессии. sudo numberbot web-access выпускает одноразовый код из интерактивной консоли.

Кнопка «Параметры файла» на экране обработки открывает выбор листа 1/2, столбцов A/B или A/C, заголовка и TXT-кодировки. Произвольные диапазоны, листы и составные столбцы вводятся прежними текстовыми командами. Бот не загружает файл ради отображения параметров.
