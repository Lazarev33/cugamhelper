# Развёртывание

Начните с [установки доверенного ключа и подписанного ZIP](SUPPLY_CHAIN.md). Кандидат с тестовой подписью предназначен для изолированной приёмки. Поддерживаемая область — Linux x86-64, systemd и системный CPython 3.11–3.13.

После установки проверьте sudo numberbot trust-status, sudo numberbot worker-status и sudo numberbot api-status. Токен и владельца настройте в TUI. Первый вход через SSH-туннель ssh -N -L 8765:127.0.0.1:8765 пользователь@VPS, затем http://localhost:8765 и код sudo numberbot web-access. Для запрета подкачки нужен cgroup v2.

Внешний HTTPS настраивается через sudo numberbot api-config и sudo numberbot proxy. Проверьте итоговый Caddyfile, сохраните существующие сайты и примените Caddy. Версия Caddy должна поддерживать request_body. У прокси отключают дисковую буферизацию, логирование тел и секретных заголовков. Целевой домен и сертификат проверяются при приёмке.

Python 3.10 остаётся в старой инфраструктурной ветке. Для hardening найденные advisory Pillow 12.x требуют обновления до Pillow 13, который требует Python 3.11+. Перед переходом с Ubuntu 22.04 подготовьте поддерживаемый системный Python на другой установке, например Ubuntu 24.04. Проверка совместимости происходит до привилегированного запуска кода из архива.
