# Изменения

## 3.1.0 · кандидат

- Ed25519-манифест, проверка архива, ограничения ZIP и порог ранее принятых версий. Сетевое обновление получает подписанный релиз.
- Точные версии Python и SHA-256 колёс. Подготовка и тесты выполняются через непривилегированного пользователя.
- Worker документов и фото с отдельным UID, сокетом и системными лимитами.
- Предпросмотр хранения, ротация, проверка копий, восстановление с закрытием прежних допусков и сессий.
- Одноразовое подтверждение критических операций через VPS, выход из всех веб-сессий.
- Агрегаты API и экспорта, диагностика и интерактивные параметры документов.
- API v1 и OpenAPI сохранены.
